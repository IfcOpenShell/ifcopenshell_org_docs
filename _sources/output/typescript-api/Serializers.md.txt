(typescript-serializers-exporttobuffer)=


### exportToBuffer()

> **exportToBuffer**(`file`, `geomSettings`, `format`, `options?`): `Promise`\<[`ExportResult`](#typescript-serializers-exportresult) \| `null`\>

Defined in: [ifcopenshell-js/src/serializers/index.ts:60](https://github.com/IfcOpenShell/IfcOpenShell/blob/c62d54a74ee67133d12f103a16831f0c510fbb91/src/ts/ifcopenshell-js/src/serializers/index.ts#L60)

Serialize the file into in-memory text buffers. Load kernel, mapping and serializer plugins first.

OBJ returns its material data in `secondary`; SVG and TTL return an empty
secondary buffer. The function returns `null` when the native iterator
cannot initialize and throws when a serializer or geometry element fails.
