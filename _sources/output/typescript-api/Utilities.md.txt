(typescript-utilities-hashcolor)=


### hashColor()

> **hashColor**(`input`): [`RGB`](#typescript-utilities-rgb)

Defined in: [ifcopenshell-js/src/util/color.ts:23](https://github.com/IfcOpenShell/IfcOpenShell/blob/403f8ceb78e3921cb183b935d885684aa2efd532/src/ts/ifcopenshell-js/src/util/color.ts#L23)

Generate a deterministic RGB color from a string hash.

Uses an FNV-1a style hash so that the same input always maps to the same
color — handy for assigning consistent display colors to IFC entity
types (e.g. `hashColor('IfcWall')`).

Components are returned in the `[0, 1]` range and deliberately biased
away from pure black / pure white so they remain visible on both light
and dark backgrounds.

#### Parameters

##### input

`string`

Arbitrary string to hash.

#### Returns

[`RGB`](#typescript-utilities-rgb)

A deterministic `[r, g, b]` triplet in `[0, 1]`.

(typescript-utilities-meshcolor)=


### meshColor()

> **meshColor**(`type`, `materialIds`, `colors`): [`RGB`](#typescript-utilities-rgb)

Defined in: [ifcopenshell-js/src/util/color.ts:50](https://github.com/IfcOpenShell/IfcOpenShell/blob/403f8ceb78e3921cb183b935d885684aa2efd532/src/ts/ifcopenshell-js/src/util/color.ts#L50)

Resolve the display color for a mesh, preferring material colors
defined on the IFC representation over a type-based hash color.

The `colors` buffer follows the IfcOpenShell convention: each material
contributes four consecutive floats (`[r, g, b, a]`), and `materialIds`
maps each face item to a material index. When a material color is
available it is used directly; otherwise the entity `type` is hashed to
produce a stable fallback color.

#### Parameters

##### type

`string`

IFC entity type name (e.g. `'IfcWall'`).

##### materialIds

`ArrayLike`\<`number`\>

Per-face material indices (may be empty).

##### colors

`ArrayLike`\<`number`\>

Flat RGBA material color buffer (may be empty).

#### Returns

[`RGB`](#typescript-utilities-rgb)

A `[r, g, b]` triplet in `[0, 1]`.
